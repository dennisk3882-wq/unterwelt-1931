# GameDeck S26 v15 – Native Upgrade

Built on original v14 Eden-based Android sources.

* Persistent favourites and sorting mode
* Full collapse of search/filter header on game list scrolling
* Optional larger game cover layout
* Per-title real launch count and last-start date on details screen
* User-controlled JSON export and import of GameDeck library/launcher preferences through Android SAF
* Existing native Eden game launch, external display, controller navigation, screenshots, technical diagnosis and advanced emulator settings retained

The app remains native. The exported settings backup excludes game images, ROMs, NAND, save games and emulator keys. Build output must be validated with apksigner and tested on S26 Ultra before claiming device compatibility.
